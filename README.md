# Skin Cancer Detection AI

AI model for skin cancer detection using deep learning.

## Overview
- **Dataset**: HAM10000 (10,015 dermoscopy images, 7 classes)
- **Model**: EfficientNet-B4 with Transfer Learning
- **Explainability**: Grad-CAM heatmaps
- **Deployment**: FastAPI + Streamlit + Docker
